# AI covenant

Whoever submits a contribution owns it, whatever tools helped.[^covenant] In this repository:[^covenant]

- an element cites by number, only a number a public source gives, and never quotes;
- no ISO text goes into the schema, the examples, the docs or the bundle, and a reader looks the wording up in a licensed copy by the number the element cites;
- ISO's metadata records are upstream data and are never edited;
- everything the schema defines lives under the project's own namespace.
