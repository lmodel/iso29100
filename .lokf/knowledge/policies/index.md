# Policies

* [AI covenant](ai-covenant.md) - The rules for AI-assisted work here: whoever submits owns the contribution, an element cites by number and never quotes, no ISO text goes anywhere in the repository, and ISO's metadata records are never edited.
* [Licence and attribution](license-and-attribution.md) - Whose work each part is: the code and schema under Apache-2.0, the bundle under CC BY 4.0, ISO's metadata records under ODC-By, DPV's mapping under the W3C Software and Document License, and the standard's text, which the repository does not hold.
* [Security policy](security-policy.md) - How to report a vulnerability in this repository, by GitHub's private reporting, what executes here and what holds each surface. A problem in the standard belongs with its committee.
